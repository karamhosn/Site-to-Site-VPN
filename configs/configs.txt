IPsec VPN Configuration Steps:


1. IP addressing to all routers and host PCs.

Refer to the addressing table.


2. OSPF configurations on all routers.


HQ-R:

en
conf t

router ospf 10
router-id 1.1.1.1

network 10.10.10.0 0.0.0.3 area 0
network 192.168.10.0 0.0.0.255 area 0
ex 

do wr


ISP:

en
conf t

router ospf 10
router-id 1.1.1.2

network 100.50.10.0 0.0.0.3 area 0
network 100.50.10.4 0.0.0.3 area 0
ex 

do wr


BR-R:

en
conf t

router ospf 10
router-id 1.1.1.3

network 10.10.10.4 0.0.0.3 area 0
network 192.168.20.0 0.0.0.255 area 0
ex 

do wr


3. IP addressing on ASA Firewall + security zones.

HQ-FWL:

en
conf t

int gig1/1
no shut
ip add 100.50.10.2 255.255.255.252
nameif OUTSIDE
security-level 0
ex 

int gig1/2
no shut
ip add 10.10.10.2 255.255.255.252
nameif INSIDE
security-level 100
ex 

wr mem

security-level 0

int gig1/2

4. Firewall inspection policies on the ASA Firewall.


HQ-FWL:

access-list RES extended permit icmp any any
access-list RES extended permit tcp any any eq 80
access-list RES extended permit tcp any any eq 443

access-group RES in interface OUTSIDE
wr mem


BRANCH-FWL:

access-list RES1 extended permit icmp any any
access-list RES1 extended permit tcp any any eq 80
access-list RES1 extended permit tcp any any eq 443

access-group RES1 in interface OUTSIDE
wr mem


5. OSPF + default routes on ASA FWL.


HQ-FWL:

router ospf 10
router-id 1.1.1.6
network 100.50.10.0 255.255.255.252 area 0
network 10.10.10.0 255.255.255.252 area 0
ex

wr mem


BRANCH-FWL:

route OUTSIDE 0.0.0.0 0.0.0.0 100.50.10.5

router ospf 10
router-id 1.1.1.7
network 100.50.10.4 255.255.255.252 area 0
network 10.10.10.4 255.255.255.252 area 0
ex

wr mem


6. Test end-to-end communication.

Ping a PC in the BRANCH site using any PC in the HQ site or vice versa.


7. Configure site-to-site IPsec VPN on the ASA Firewall: Create crypto ikev1 policy, tunnel group to specify pre-shared key, IPsec transform set, ACL to identify traffic of interest, create crypto map, ennable ikev1 and apply crypto map on the interface.

HQ-FWL:

en
conf t

crypto ikev1 policy 10
hash sha
authentication pre-share
group 2
lifetime 86400
encryption 3des
ex 

tunnel-group 100.50.10.6 type IPsec-l2l
tunnel-group 100.50.10.6 IPsec-attributes
ikev1 pre-shared-key cisco
ex 

crypto ipsec ikev1 transform-set TSET esp-3des esp-sha-hmac

access-list VPN-ACL permit ip 192.168.10.0 255.255.255.0 192.168.20.0 255.255.255.0

crypto map CMAP 10 set peer 100.50.10.6
crypto map CMAP 10 set ikev1 transform-set TSET
crypto map CMAP 10 match address VPN-ACL

crypto map CMAP interface OUTSIDE
crypto ikev1 enable OUTSIDE
wr mem


BRANCH-FWL:

en
conf t

crypto ikev1 policy 10
hash sha
authentication pre-share
group 2
lifetime 86400
encryption 3des
ex 

tunnel-group 100.50.10.2 type IPsec-l2l
tunnel-group 100.50.10.2 IPsec-attributes
ikev1 pre-shared-key cisco
ex 

crypto ipsec ikev1 transform-set TSET esp-3des esp-sha-hmac

access-list VPN-ACL permit ip 192.168.20.0 255.255.255.0 192.168.10.0 255.255.255.0

crypto map CMAP 10 set peer 100.50.10.2
crypto map CMAP 10 set ikev1 transform-set TSET
crypto map CMAP 10 match address VPN-ACL

crypto map CMAP interface OUTSIDE
crypto ikev1 enable OUTSIDE
wr mem
